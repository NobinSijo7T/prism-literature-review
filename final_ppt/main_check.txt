01. Introduction: PrismSpace Web Platform


       ▶ A multi-agent system breaks complex goals into smaller tasks, assigns them to suitable agents,
         runs independent tasks in parallel, and combines their results.

       ▶ PrismSpace is a web-based multi-agent intelligence platform designed to coordinate AI agents
         and manage complex workflows.

       ▶ It converts natural-language goals into Directed Acyclic Graphs (DAGs) to manage task
         dependencies and enable parallel execution.

       ▶ It provides real-time workflow visualization, local session storage, and human approval controls
         for sensitive actions.

02. Problem Statement: Core Challenges in AI Agent Systems

     ▶ Coordinating multiple AI agents and complex tasks requires efficient task
       orchestration, seamless tool integration, clear workflow visibility, and
       secure execution.

     ▶ Developer task prompts, workspace and session state, uploaded files, and
       MCP and human approval configurations.

     ▶ PrismSpace applies intent classification, supervised model routing, DAG
       decomposition with topological scheduling, MCP-based tool execution,
       ORPO preference alignment, and human approval for sensitive actions.

     ▶ Task results, tool outputs, validation results, and workflow status
       summaries.

03. Objectives


     ▶ Implement PrismSpace as a multi-agent workspace that transforms a
       user’s prompt into a verified deliverable through coordinated planning,
       tool use, and human oversight.

     ▶ Accept the user’s prompt and constraints.

     ▶ Classify intent, generate a dependency-aware DAG, route subtasks to
       specialist agents, execute approved MCP tools, and validate progress with
       HITL safeguards.

     ▶ Synthesize and deliver a verified result while showing task progress and
       preserving the session state.

Research Gap

What the surveyed methods already do
ORPO (Odds Ratio Preference Optimization) trains Large Language Models (LLMs) to prefer better responses without
requiring a separate reference model. DAG (Directed Acyclic Graph) schedulers organize tasks based on their
dependencies to ensure they run in the correct order.


Limitations observed in those papers
Most multi-agent coordination methods are tested in games such as SMAC (StarCraft Multi-Agent Challenge) and
Overcooked rather than real developer tools. ORPO is not specifically designed to learn from Model Context Protocol
(MCP) tool-use traces. DAG-based schedulers often rely on predefined task dependencies and do not fully support
dynamic task routing based on the changing needs of LLMs. These methods lack a unified approach that combines
tool-aware agents, preference alignment, and dynamic task execution in a developer workspace.


Why PrismSpace is required
PrismSpace combines tool-aware AI agents, ORPO-based preference alignment, dynamic LLM routing, and DAG-based
task coordination in one developer workspace. It helps agents select suitable tools, coordinate complex tasks, and adapt
task execution to changing requirements.

How ORPO Works: Preference Alignment and Quality Gating

 8 What is ORPO & Why is it Used Here as a Reward System?
 • What is ORPO? Odds Ratio Preference Optimization (ORPO) is an integrated single-stage reward and alignment algorithm. Traditional Reinforcement Learning from Human Feedback (RLHF)
 requires training a separate reward model and keeping a frozen reference model in GPU memory (heavy, slow, and unstable).
 • Why in PrismSpace? In multi-agent swarms, LLMs can hallucinate invalid tools or malformed code. ORPO acts as an internal reward filter: it mathematically rewards compliant trajectories (yw )
 and penalizes bad responses (yl ) during fine-tuning, eliminating the need for an external reward model.

Modules, responsibilities, and system-level organization
System Modules and Responsibilities
 ▶ User and Session Module: captures objectives, settings, conversation history, uploaded files, and session state.
 ▶ Context and Routing Module: classifies intent and selects the most suitable provider, model, and specialist agents.
 ▶ DAG (Directed Acyclic Graph) Planning Module: decomposes objectives into dependency-aware subtasks and
   schedules parallel work.
 ▶ MCP (Model Context Protocol) Integration Module: exposes filesystem, terminal, database, memory, and
   external-service tools through JSON-RPC (JavaScript Object Notation–Remote Procedure Call).
 ▶ Verification and Safety Module: applies schema checks, ORPO (Odds Ratio Preference Optimization) preference
   gating, anomaly detection, and HITL (Human-in-the-Loop) approvals.
