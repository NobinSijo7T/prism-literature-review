01. Introduction: PrismSpace Web Platform


       ▶ A multi-agent system breaks complex goals into smaller tasks, assigns them to suitable agents,
         runs independent tasks in parallel, and combines their results.

       ▶ PrismSpace is a web-based multi-agent intelligence platform designed to coordinate AI agents
         and manage complex workflows.

       ▶ It converts natural-language goals into Directed Acyclic Graphs (DAGs) to manage task
         dependencies and enable parallel execution.

       ▶ It provides real-time workflow visualization, local session storage, and human approval controls
         for sensitive actions.

02. Problem Statement: Core Challenges in AI Agent Systems

     ▶ Problem: Coordinating multiple AI agents and complex tasks requires
       efficient task orchestration, seamless tool integration, clear workflow
       visibility, and secure execution.

     ▶ Input: Developer task prompts, workspace and session state, uploaded
       files, and MCP and human approval configurations.

     ▶ Method: PrismSpace applies intent classification, supervised model
       routing, DAG decomposition with topological scheduling, MCP-based tool
       execution, ORPO preference alignment, and human approval for sensitive
       actions.

     ▶ Output: Task results, tool outputs, validation results, and workflow
       status summaries.

03. Objectives

        1   Intent Classification Module: Identifies user intent and classifies incoming
            prompts.
        2   DAG Generation Module: Decomposes user goals into dependency-aware subtasks
            and schedules their execution.
        3   Agent Routing Module: Assigns tasks to suitable agents based on task
            requirements.
        4   MCP Tool Integration Module: Connects approved external tools and manages
            tool execution.
        5   Validation and Human Approval Module: Validates outputs and requests human
            approval for sensitive actions.
        6   Workflow Visualization and Session Management Module: Displays real-time
            task progress and stores session data locally.

Research Gap

What the surveyed methods already do
MARL works address CTDE, role grouping, and ad-hoc coordination. ORPO aligns LLM preferences without reference
models, while HIAT leverages human interventions as auxiliary RL signals. CPN-HRL and DAG schedulers optimize cloud
task allocation, and MHC formalizes tracking and tracing properties.


Limitations observed in those papers
Coordination benchmarks focus on gaming (SMAC, Overcooked) rather than filesystem/API tooling. ORPO lacks
grounding in MCP ReAct tool traces, while HIAT targets continuous robotic control instead of code execution. Cloud
schedulers assume static DAGs or slow metaheuristics ill-suited for real-time LLM routing.


Why PrismSpace is required
No reviewed system jointly grounds tool observations, aligns policies on agent trajectories, dynamically routes
heterogeneous LLMs, and enforces human-in-the-loop safety gates within a unified developer workspace.

How ORPO Works: Preference Alignment and Quality Gating

 8 What is ORPO & Why is it Used Here as a Reward System?
 • What is ORPO? Odds Ratio Preference Optimization (ORPO) is an integrated single-stage reward and alignment algorithm. Traditional Reinforcement Learning from Human Feedback (RLHF)
 requires training a separate reward model and keeping a frozen reference model in GPU memory (heavy, slow, and unstable).
 • Why in PrismSpace? In multi-agent swarms, LLMs can hallucinate invalid tools or malformed code. ORPO acts as an internal reward filter: it mathematically rewards compliant trajectories (yw )
 and penalizes bad responses (yl ) during fine-tuning, eliminating the need for an external reward model.
