\begin{itemize}
    \item \textbf{Vision Language Model (VLM): Florence-2 - Capabilities \& Fine-Tuning Strategy}
    
    \vspace{0.3cm}
    
    \begin{itemize}
        \item \textbf{Phrase Grounding:} Florence-2's most critical feature for our project. It can take a text phrase (e.g., "the search bar") and output the precise bounding box coordinates of that object within the image. This is the core mechanism for visually locating UI elements.
        
        \vspace{0.25cm}
        
        \item \textbf{Advanced OCR:} It excels at reading text directly from images, allowing our agent to understand buttons, labels, and inputs without accessing the website's code.
        
        \vspace{0.25cm}
        
        \item \textbf{Efficiency:} The Florence-2-base model is significantly smaller and more specialized than general-purpose 7B+ parameter VLMs, making it faster and more efficient for our specific task.
    \end{itemize}

\end{itemize}
