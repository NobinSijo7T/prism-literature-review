    \item \textbf{Vision Language Model (VLM): Florence-2 - Capabilities \& Fine-Tuning Strategy}
    
    \vspace{0.3cm}
    
    \begin{itemize}
        \item Florence-2 is a highly capable vision foundation model, not just a generic VLM. It is built on a unified, prompt-based, sequence-to-sequence architecture.
        
        \vspace{0.3cm}
        
        \item This design allows it to perform a vast range of vision tasks (from captioning to object detection) using a single, cohesive model.
        
        \vspace{0.3cm}
        
        \item Its core strength lies in its ability to understand and execute tasks based on a combination of an image and a text prompt, making it a powerful and flexible tool for visual analysis.
    \end{itemize}

\end{itemize}
