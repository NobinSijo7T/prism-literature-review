\begin{itemize}
     \item \textbf{SVM Active Learning} - A classification-based \textbf{STL} approach that trains a Support Vector Machine on user-labelled relevant and irrelevant images to re-rank subsequent results.
        
    \item \textbf{Multi-Encoder Fusion} - Combines multiple text encoders to improve retrieval in RAG systems. Each encoder captures different aspects of semantic similarity, and their outputs are merged for broader coverage.

    % \item \textbf{Learnable Fusion Weights} - A neural network is trained to assign an optimal weight to each encoder's output. These weights are learned from data rather than set manually.

    \item \textbf{Mean Reciprocal Rank (\textbf{MRR})} - The evaluation metric used; measures how highly the first relevant result is ranked on average. The multi-encoder approach achieved a 6\% \textbf{MRR} improvement over single-encoder baselines.
\end{itemize}
