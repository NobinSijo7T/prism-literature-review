\frametitle{Background}

\begin{itemize}
    \item \textbf{Rmeasure} - A framework to evaluate search engine consistency by measuring how stable result rankings are across repeated identical queries.

    \item \textbf{Roverlap} - Measures rank stability among results that appear in \emph{both} repetitions of a query. Compares position changes for common URLs; a higher value indicates more stable ranking.

    \item \textbf{Rnon-overlap} - Measures stability for results that appear in one query repetition but not the other. Captures the volatility of results that appear or disappear between queries.

    % \item \textbf{Psychophysical Modeling} - User perception of rank changes is incorporated into the metric. Small positional shifts near the top are weighted more heavily than shifts lower down.
\end{itemize}
