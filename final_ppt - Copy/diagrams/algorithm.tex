\subsection*{4.5\quad Algorithm of PrismSpace Multi-Agent System}

The PrismSpace algorithm orchestrates multiple specialized AI agents into a coordinated swarm: interpreting user objectives, routing tasks to the optimal LLM provider, dispatching specialized agents, equipping them with tools, and verifying safety and accuracy. The workflow operates in three distinct phases:
\begin{itemize}[leftmargin=1.5em, itemsep=0.03em, topsep=0.02em]
    \item \textbf{Phase I: Offline Swarm Graph Representation} (Steps 1--5: Data prep, swarm graph, GAT routing)
    \item \textbf{Phase II: Single-Stage Preference Alignment} (Step 6: Safety and quality tuning via ORPO)
    \item \textbf{Phase III: Online Runtime Inference \& Swarm Execution} (Steps 7--9: Live execution, evaluation, telemetry)
\end{itemize}

\vspace{0.08em}
\textbf{Inputs (What Goes In):}
\begin{itemize}[leftmargin=1.5em, itemsep=0.03em, topsep=0.02em]
    \item \textbf{User Objective ($\mathcal{T}_{\text{user}}$):} Natural language user prompt, operational scope, and execution constraints.
    \item \textbf{Curated Training Corpora ($\mathcal{D}$):} Multi-source benchmark datasets containing prompt traces, intent categories, safety evaluations (WildGuard), and multi-agent trajectories (RouterBench, LMSYS Arena, CMU Agent Benchmark).
    \item \textbf{Preference Alignment Pairs ($\mathcal{D}_{\text{pref}} = \{(x, y_w, y_l)\}$):} Prompt $x$ paired with preferred response $y_w$ and disfavored response $y_l$.
    \item \textbf{Global Agent Swarm Registry ($\mathcal{G}_{\text{global}} = (V, E)$):} Roster of specialized AI agents (Supervisor, Coding, Research, Validator, Planner) and Model Context Protocol (MCP) tool endpoints.
\end{itemize}

\vspace{0.08em}
\textbf{Outputs (What Comes Out):}
\begin{itemize}[leftmargin=1.5em, itemsep=0.03em, topsep=0.02em]
    \item \textbf{Task Intent \& Best Provider:} Predicted task category ($\hat{y}_{\text{intent}}$) and optimal LLM provider ($\hat{y}_{\text{provider}}$, e.g., Groq for rapid response, OpenAI/Anthropic for complex reasoning).
    \item \textbf{Swarm Dispatch Vector ($\hat{\mathbf{y}}_{\text{agents}}$):} Binary activation checklist ($1$ = active, $0$ = idle) for each agent in $V$.
    \item \textbf{Execution Plan ($\mathcal{G}_{\text{active}}$):} Directed Acyclic Graph (DAG) outlining task steps with predicted latency ($\hat{\ell}$) and cost ($\hat{c}$).
    \item \textbf{Tuned Model Adapters ($\Delta \mathbf{W}$):} Lightweight LoRA weights ensuring helpfulness and safety compliance.
    \item \textbf{Evaluation Metrics:} Quantitative benchmarks including Accuracy, F1-Score, ROC-AUC, and ECE calibration.
\end{itemize}

\vspace{0.12em}
\textbf{Step 1: Data collection and Preprocessing}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.10em, topsep=0.03em]
    \item Import and unify raw records across multi-source benchmark datasets ($\mathcal{D}$), mapping heterogeneous prompt schemas, classification labels, and tool invocation logs into a structured, unified schema.
    \item Clean and sanitize the textual dataset by stripping malformed Unicode sequences, removing redundant whitespace tokens, trimming uninformative control characters, and filtering duplicate prompt-response pairs.
    \item Perform categorical encoding across discrete metadata attributes (agent role definitions, tool protocol capabilities, provider endpoints) into dense numerical vectors.
    \item Standardize continuous numerical features (token length, baseline query complexity, empirical latency traces) using $z$-score normalization:
    \begin{equation*}
    z = \frac{x - \mu}{\sigma}
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $z$: Standardized continuous feature score with zero mean ($\mu = 0$) and unit variance ($\sigma = 1$), eliminating scale disparities across heterogeneous features.
        \item $x$: Raw continuous feature measurement (e.g., prompt token length, query complexity score, empirical execution latency).
        \item $\mu$: Empirical arithmetic mean of the feature calculated across the training set $\mathcal{D}_{\text{train}}$.
        \item $\sigma$: Empirical standard deviation of the feature calculated across $\mathcal{D}_{\text{train}}$, quantifying feature dispersion.
    \end{itemize}
    \item Partition the processed dataset via stratified random sampling into three non-overlapping subsets:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.02em, topsep=0.01em, label=$\ast$]
        \item 80\% Training set ($\mathcal{D}_{\text{train}}$) for model parameter optimization and graph embedding learning
        \item 10\% Validation set ($\mathcal{D}_{\text{val}}$) for hyperparameter tuning, pruning, and early stopping
        \item 10\% Testing set ($\mathcal{D}_{\text{test}}$) for unbiased evaluation of routing accuracy and safety alignment
    \end{itemize}
\end{enumerate}

\textbf{Step 2: Swarm Graph Construction}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.12em, topsep=0.03em]
    \item Define the node set ($V$): represent each specialized AI agent persona (Supervisor, Research, Coding, Validator, Planner) and each Model Context Protocol (MCP) tool as an individual vertex $v_i \in V$.
    \item Evaluate pairwise functional capability similarity: compute the Pearson correlation coefficient between node capability vectors $\mathbf{x}_i$ and $\mathbf{x}_j$:
    \begin{equation*}
    s_{ij} = \frac{\mathrm{Cov}(\mathbf{x}_i, \mathbf{x}_j)}{\sigma_i \, \sigma_j}
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $s_{ij}$: Pearson correlation similarity coefficient between nodes $v_i$ and $v_j$, bounded in $[-1, 1]$.
        \item $\mathbf{x}_i, \mathbf{x}_j$: Functional capability and interface feature vectors representing nodes $v_i$ and $v_j$.
        \item $\mathrm{Cov}(\mathbf{x}_i, \mathbf{x}_j)$: Joint covariance measuring how capability attributes of nodes $v_i$ and $v_j$ co-vary.
        \item $\sigma_i, \sigma_j$: Marginal standard deviations of capability feature distributions $\mathbf{x}_i$ and $\mathbf{x}_j$.
    \end{itemize}
    \item Establish collaborative topological connections: generate binary adjacency matrix $\mathbf{A}$ by thresholding similarity against cutoff $\tau$:
    \begin{equation*}
    A_{ij} = \begin{cases} 1 & \text{if } s_{ij} \ge \tau \\ 0 & \text{otherwise} \end{cases}
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $A_{ij}$: Binary connectivity entry in adjacency matrix $\mathbf{A} \in \{0, 1\}^{|V| \times |V|}$, denoting presence ($1$) or absence ($0$) of an active collaborative edge between nodes $v_i$ and $v_j$.
        \item $s_{ij}$: Pairwise Pearson correlation similarity coefficient between nodes $v_i$ and $v_j$.
        \item $\tau$: Empirical correlation cutoff threshold regulating swarm topology density and pruning weak pairings.
    \end{itemize}
    \item Construct the global swarm topology $\mathcal{G} = (V, E)$: establish undirected collaborative communication edges $E$ that permit message propagation exclusively between complementary agent and tool pairings.
\end{enumerate}

\vspace{0.20em}
\textbf{Step 3: Graph Attention Network (GAT) Initialization}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.12em, topsep=0.03em]
    \item Initialize node representations: assign each vertex $v_i \in V$ an initial $d$-dimensional feature embedding vector:
    \begin{equation*}
    \mathbf{h}_i = \mathbf{x}_i \in \mathbb{R}^d, \qquad \mathbf{W} \in \mathbb{R}^{d' \times d}, \qquad \mathbf{a} \in \mathbb{R}^{2d'}
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathbf{h}_i$: Initial feature representation vector assigned to vertex $v_i \in V$.
        \item $\mathbf{x}_i$: Raw input attribute vector of vertex $v_i$ encoding operational scope and tool interfaces.
        \item $d$: Dimensionality of input feature space.
        \item $\mathbf{W}$: Shared learnable linear projection weight matrix mapping input features to latent dimension $d'$.
        \item $d'$: Projected latent feature representation dimensionality.
        \item $\mathbf{a}$: Learnable shared attention mechanism vector used to compute inter-node attention scores.
    \end{itemize}
    \item Initialize projection and attention parameters: instantiate weight projection matrix $\mathbf{W}$ and attention vector $\mathbf{a}$ via Xavier uniform initialization, ensuring stable variance across forward and backward signal propagation.
    \item Configure network hyperparameters: establish learning rate $\eta$, attention head count $K$ (specialized across task intent, model capability, swarm affinity, and safety constraints), and dropout regularization probability $p$.
\end{enumerate}

\textbf{Step 4: Attention-Based Message Passing}

For each node $v_i$ with immediate collaborative neighborhood $\mathcal{N}(i)$:
\begin{enumerate}[leftmargin=1.8em, itemsep=0.08em, topsep=0.02em]
    \item Compute raw attention coefficients with connected neighbors $v_j \in \mathcal{N}(i)$:
    \begin{equation*}
    e_{ij} = \mathrm{LeakyReLU}\Big(\mathbf{a}^T [\mathbf{W} \mathbf{h}_i \,\|\, \mathbf{W} \mathbf{h}_j]\Big)
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $e_{ij}$: Raw unnormalized attention coefficient indicating communicative significance of neighbor $v_j$ to node $v_i$.
        \item $\mathbf{a} \in \mathbb{R}^{2d'}$: Parameterized shared attention mechanism weight vector.
        \item $\mathbf{a}^T$: Transpose of attention vector $\mathbf{a}$, computing inner product with concatenated node representations.
        \item $\mathbf{W} \in \mathbb{R}^{d' \times d}$: Shared linear feature projection matrix applied to each node representation.
        \item $\mathbf{h}_i, \mathbf{h}_j$: Current hidden state feature vectors of receiving node $v_i$ and neighboring source node $v_j$.
        \item $\|$: Vector concatenation operator joining projected vectors $\mathbf{W}\mathbf{h}_i$ and $\mathbf{W}\mathbf{h}_j$ into a single $2d'$-dimensional vector.
        \item $\mathrm{LeakyReLU}(\cdot)$: Non-linear activation function allowing gradient flow even for negative inputs.
    \end{itemize}
    \item Normalize coefficients across the local neighborhood using Softmax:
    \begin{equation*}
    \alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k \in \mathcal{N}(i)} \exp(e_{ik})}
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\alpha_{ij}$: Normalized attention weight representing communicative attention directed from node $v_i$ to neighbor $v_j$, satisfying $\sum_{j \in \mathcal{N}(i)} \alpha_{ij} = 1$.
        \item $e_{ij}$: Raw attention coefficient computed between target node $v_i$ and neighbor $v_j$.
        \item $\mathcal{N}(i)$: Neighborhood vertex set containing all nodes directly connected to node $v_i$ in swarm topology $\mathcal{G}$.
        \item $\exp(\cdot)$: Natural exponential function guaranteeing strictly positive weights.
        \item $\sum_{k \in \mathcal{N}(i)} \exp(e_{ik})$: Softmax normalization denominator summing exponentiated attention scores across all neighbors of node $v_i$.
    \end{itemize}
    \item Aggregate neighborhood feature representations (single-head aggregation):
    \begin{equation*}
    \mathbf{h}_i' = \sigma\left(\sum_{j \in \mathcal{N}(i)} \alpha_{ij} \mathbf{W} \mathbf{h}_j\right)
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathbf{h}_i'$: Updated, context-aware output feature representation vector for node $v_i$.
        \item $\sigma(\cdot)$: Non-linear activation function (such as Exponential Linear Unit, ELU).
        \item $\alpha_{ij}$: Normalized attention weight scaling the message representation of neighbor $v_j$.
        \item $\mathbf{W}$: Linear feature projection weight matrix.
        \item $\mathbf{h}_j$: Hidden feature vector of neighboring node $v_j$.
        \item $\mathcal{N}(i)$: Direct neighborhood set of node $v_i$.
    \end{itemize}
    \item Multi-head attention concatenation across $K$ independent attention heads:
    \begin{equation*}
    \mathbf{h}_i' = \Vert_{k=1}^K \sigma\left(\sum_{j \in \mathcal{N}(i)} \alpha_{ij}^k \mathbf{W}^k \mathbf{h}_j\right)
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathbf{h}_i'$: Final concatenated multi-head embedding of node $v_i$, of dimension $K \cdot d'$.
        \item $\Vert_{k=1}^K$: Vector concatenation operator combining representations learned across all $K$ independent attention heads.
        \item $K$: Total count of parallel attention heads specialized across distinct collaborative dimensions.
        \item $\alpha_{ij}^k$: Normalized attention coefficient produced by the $k$-th attention head for neighbor $v_j$.
        \item $\mathbf{W}^k$: Transformation weight matrix parameterized specifically for the $k$-th attention head.
        \item $\mathbf{h}_j$: Feature vector of neighbor $v_j$.
        \item $\sigma(\cdot)$: Non-linear activation function.
    \end{itemize}
\end{enumerate}

\textbf{Step 5: Classification and Loss Computation}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.12em, topsep=0.03em]
    \item Route updated swarm representations $\mathbf{h}_i'$ through dual specialized prediction heads:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.04em, topsep=0.02em, label=$\ast$]
        \item \textit{Intent \& Provider Routing Head:} Computes normalized routing probabilities via Softmax:
        \begin{equation*}
        \hat{\mathbf{y}}_{\text{route}} = \mathrm{Softmax}(\mathbf{W}_{\text{route}} \mathbf{h}' + \mathbf{b}_{\text{route}})
        \end{equation*}
        where:
        \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
            \item $\hat{\mathbf{y}}_{\text{route}}$: Predicted probability distribution vector over available foundation LLM providers (e.g., Groq, OpenAI, Anthropic).
            \item $\mathbf{W}_{\text{route}}$: Trainable projection weight matrix for the routing classification head.
            \item $\mathbf{h}'$: Graph-level pooled feature embedding summarizing the entire swarm graph and user query.
            \item $\mathbf{b}_{\text{route}}$: Trainable additive bias vector of the routing head.
            \item $\mathrm{Softmax}(\cdot)$: Normalization function converting raw logit scores into valid probabilities summing to $1$.
        \end{itemize}
        \item \textit{Agent Dispatch Head:} Evaluates independent activation probabilities per agent persona via element-wise Sigmoid:
        \begin{equation*}
        \hat{y}_{\text{agent}, i} = \mathrm{Sigmoid}(\mathbf{W}_{\text{agent}} \mathbf{h}_i' + b_i)
        \end{equation*}
        where:
        \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
            \item $\hat{y}_{\text{agent}, i}$: Predicted activation probability in $[0, 1]$ indicating whether agent persona $v_i$ should be dispatched.
            \item $\mathbf{W}_{\text{agent}}$: Trainable projection parameter vector for multi-label agent dispatching.
            \item $\mathbf{h}_i'$: Contextualized feature embedding of node $v_i$ output by the multi-head GAT layer.
            \item $b_i$: Trainable scalar bias term for agent node $v_i$.
            \item $\mathrm{Sigmoid}(\cdot)$: Logistic activation function mapping real-valued logits to independent probabilities in $[0, 1]$.
        \end{itemize}
    \end{itemize}
    \item Compute unified multi-task loss ($\mathcal{L}_{\text{class}}$) combining routing cross-entropy and agent dispatch cross-entropy:
    \begin{equation*}
    \mathcal{L}_{\text{class}} = \mathcal{L}_{\text{CE}}(\mathbf{y}_{\text{route}}, \hat{\mathbf{y}}_{\text{route}}) + \lambda \sum_{v \in V} \mathcal{L}_{\text{BCE}}(y_v, \hat{y}_v)
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathcal{L}_{\text{class}}$: Total multi-task joint classification objective minimized during offline training.
        \item $\mathcal{L}_{\text{CE}}$: Categorical Cross-Entropy loss measuring routing classification error against ground truth.
        \item $\mathbf{y}_{\text{route}}$: Ground-truth one-hot target vector representing optimal provider selection.
        \item $\hat{\mathbf{y}}_{\text{route}}$: Model-predicted probability vector over provider classes.
        \item $\mathcal{L}_{\text{BCE}}$: Binary Cross-Entropy loss evaluating activation prediction for each candidate agent node $v$.
        \item $y_v$: Ground-truth binary activation label ($1$ if agent $v$ is required, $0$ otherwise).
        \item $\hat{y}_v$: Predicted activation probability for agent $v$.
        \item $\lambda$: Regularization hyperparameter balancing provider routing accuracy against agent over-provisioning penalties.
        \item $V$: Universal set of agent persona vertices in the swarm registry.
    \end{itemize}
    \item Optimize parameters: backpropagate error gradients and update network parameters using the AdamW optimizer with cosine learning-rate decay and gradient norm clipping.
\end{enumerate}

\textbf{Step 6: Single-Stage Preference Alignment (ORPO)}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.08em, topsep=0.02em]
    \item Inject Parameter-Efficient Fine-Tuning (PEFT) adapters via low-rank decomposition matrices:
    \begin{equation*}
    \Delta \mathbf{W} = \frac{\alpha}{r} \mathbf{B}\mathbf{A}
    \end{equation*}
    where $\Delta \mathbf{W} \in \mathbb{R}^{d \times k}$ represents the low-rank incremental weight update adapter added to frozen base weights $\mathbf{W}_0$, $\mathbf{B} \in \mathbb{R}^{d \times r}$ is the trainable down-projection matrix (zero-initialized), $\mathbf{A} \in \mathbb{R}^{r \times k}$ is the trainable up-projection matrix (Gaussian initialized), $r$ is the intrinsic rank hyperparameter ($r \ll \min(d, k)$), and $\alpha$ is the LoRA scaling constant controlling update magnitude.
    \item Compute the supervised fine-tuning (SFT) objective on favored human responses ($y_w$):
    \begin{equation*}
    \mathcal{L}_{\mathrm{SFT}} = -\frac{1}{|y_w|} \sum_{t=1}^{|y_w|} \log P(y_{w,t} \mid x, y_{w,<t})
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathcal{L}_{\mathrm{SFT}}$: Negative log-likelihood sequence loss over favored human responses, maintaining fluent language syntax.
        \item $x$: Input prompt sequence representing the user objective and operational context.
        \item $y_w$: Preferred (winning) demonstration token sequence of length $|y_w|$.
        \item $y_{w,t}$: The target ground-truth token generated at step $t$.
        \item $y_{w,<t}$: Autoregressive prefix context consisting of all tokens preceding position $t$ ($y_{w,1}, \dots, y_{w,t-1}$).
        \item $P(y_{w,t} \mid x, y_{w,<t})$: Conditional probability assigned to token $y_{w,t}$ by the language model given prompt $x$ and preceding context tokens.
    \end{itemize}
    \item Calculate length-normalized sequence odds for completion sequence $y \in \{y_w, y_l\}$:
    \begin{equation*}
    \mathrm{odds}(y \mid x) = \frac{P(y \mid x)}{1 - P(y \mid x)}
    \end{equation*}
    where $\mathrm{odds}(y \mid x)$ represents the odds ratio of generating sequence $y$ given prompt $x$, $P(y \mid x)$ is the length-normalized likelihood $\big(\prod_{t=1}^{|y|} P(y_t \mid x, y_{<t})\big)^{1/|y|}$, and $1 - P(y \mid x)$ is the complementary non-generation probability.
    \item Formulate the Odds Ratio (OR) preference penalty between favored ($y_w$) and disfavored ($y_l$) completions:
    \begin{equation*}
    \mathcal{L}_{\mathrm{OR}} = -\log \sigma \left(\log \left[\frac{\mathrm{odds}(y_w \mid x)}{\mathrm{odds}(y_l \mid x)}\right]\right)
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\mathcal{L}_{\mathrm{OR}}$: Odds Ratio contrastive penalty that penalizes disfavored patterns (hallucinations, safety violations) and rewards preferred patterns.
        \item $\sigma(\cdot)$: Standard logistic sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$.
        \item $\mathrm{odds}(y_w \mid x)$: Sequence generation odds for the preferred / winning completion $y_w$.
        \item $\mathrm{odds}(y_l \mid x)$: Sequence generation odds for the disfavored / losing completion $y_l$.
        \item $\log \left[\frac{\mathrm{odds}(y_w \mid x)}{\mathrm{odds}(y_l \mid x)}\right]$: Log odds ratio measuring the log-margin difference between favored and disfavored outputs.
    \end{itemize}
    \item Optimize unified single-stage ORPO objective:
    \begin{equation*}
    \mathcal{L}_{\mathrm{ORPO}} = \mathcal{L}_{\mathrm{SFT}} + \beta \cdot \mathcal{L}_{\mathrm{OR}}
    \end{equation*}
    where $\mathcal{L}_{\mathrm{ORPO}}$ represents the composite single-stage objective minimized without external reward models, $\mathcal{L}_{\mathrm{SFT}}$ is the supervised fine-tuning loss ensuring language fluency, $\mathcal{L}_{\mathrm{OR}}$ is the odds ratio contrast loss penalizing disfavored generation modes, and $\beta$ is the regularization weighting coefficient balancing alignment against SFT fluency.
\end{enumerate}

\textbf{Step 7: Real-Time Runtime Inference and Swarm Execution}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.12em, topsep=0.03em]
    \item Capture user objective: ingest natural language prompt $\mathcal{T}_{\text{user}}$ via the Next.js client interface and securely dispatch it to the FastAPI Hive Bridge orchestration gateway.
    \item Synthesize query feature vector ($\mathbf{x}_{\text{query}}$): concatenate sparse TF-IDF n-gram vectors, dense semantic sentence embeddings, and session contextual metadata (token budget, latency requirements, user tool permissions).
    \item Determine routing and dispatch policy: assign prompt to optimal LLM provider and activate required swarm agents:
    \begin{equation*}
    \hat{y}_{\text{provider}} = \mathrm{argmax}(\hat{\mathbf{y}}_{\text{route}}), \qquad \hat{\mathbf{y}}_{\text{agents}} = \mathbb{I}(\hat{\mathbf{y}}_{\text{dispatch}} \ge \tau_{\text{dispatch}})
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\hat{y}_{\text{provider}}$: Index of selected foundation LLM provider (e.g., Groq for rapid latency, OpenAI/Anthropic for complex reasoning).
        \item $\hat{\mathbf{y}}_{\text{route}}$: Posterior probability distribution vector output by the routing prediction head.
        \item $\mathrm{argmax}(\cdot)$: Selection operator returning provider index with maximum routing probability.
        \item $\hat{\mathbf{y}}_{\text{agents}}$: Binary dispatch checklist vector ($1$ = active agent, $0$ = idle agent) defining the dispatched swarm.
        \item $\mathbb{I}(\cdot)$: Element-wise indicator function returning $1$ when condition holds and $0$ otherwise.
        \item $\hat{\mathbf{y}}_{\text{dispatch}}$: Continuous activation probability vector output by the agent dispatch head.
        \item $\tau_{\text{dispatch}}$: Calibrated activation decision threshold for triggering agent instantiation.
    \end{itemize}
    \item Formulate task DAG and execution schedule via topological sorting:
    \begin{equation*}
    \pi = \mathrm{TopologicalSort}(\mathcal{G}_{\text{active}})
    \end{equation*}
    where:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
        \item $\pi$: Linearly ordered execution schedule of subtask steps ensuring prerequisite tasks complete before downstream tasks begin.
        \item $\mathcal{G}_{\text{active}}$: Active execution Directed Acyclic Graph (DAG) whose vertices represent subtasks and directed edges denote data dependencies.
        \item $\mathrm{TopologicalSort}(\cdot)$: Graph algorithm producing a valid linear ordering where all prerequisite dependencies are satisfied.
    \end{itemize}
    \item Execute autonomous ReAct swarm loops: dispatch agents to iteratively reason, propose actions, and invoke Model Context Protocol (MCP) tool endpoints (Browser, Filesystem, GitHub, Python Sandbox), aggregating intermediate tool observation traces until all subtask criteria are satisfied.
    \item Enforce policy safety gating: evaluate final candidate completions through the calibrated safety gate, verifying that the log-odds safety score relative to reference text meets safety threshold $\tau_{\text{safety}}$, intercepting prompt injection, unsafe operations, or policy violations.
    \item Deliver real-time response and persist session state: stream verified response tokens live to the frontend via Server-Sent Events (SSE), update real-time telemetry HUD metrics, and commit complete conversation artifacts to local browser IndexedDB storage using Dexie.js.
\end{enumerate}

\textbf{Step 8: Model Evaluation}
\begin{enumerate}[leftmargin=1.8em, itemsep=0.10em, topsep=0.02em]
    \item Assess generalization performance: benchmark trained GAT routing and ORPO alignment models against holdout validation ($\mathcal{D}_{\text{val}}$) and test ($\mathcal{D}_{\text{test}}$) splits to quantify accuracy and preference adherence.
    \item Compute comprehensive quantitative validation metrics:
    \begin{itemize}[leftmargin=1.5em, itemsep=0.03em, topsep=0.01em, label=$\ast$]
        \item \textit{Routing Accuracy \& Macro-F1:} Measure proportion of correctly classified intents and provider selections, computing harmonic mean of precision and recall across rare and frequent task classes.
        \item \textit{Discrimination Capability (ROC-AUC \& AUPRC):} Measure the area under the receiver operating characteristic and precision--recall curves to assess safety gate discrimination under class imbalance.
        \item \textit{Calibration Quality (ECE):} Measure Expected Calibration Error across $M$ probability bins:
        \begin{equation*}
        \mathrm{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left|\mathrm{acc}(B_m) - \mathrm{conf}(B_m)\right|
        \end{equation*}
        where:
        \begin{itemize}[leftmargin=1.5em, itemsep=0.01em, topsep=0.01em]
            \item $\mathrm{ECE}$: Expected Calibration Error, quantifying overall alignment between predicted confidence scores and observed empirical accuracy.
            \item $M$: Number of discrete confidence bins partitioning the prediction score interval $[0, 1]$ (e.g., $M = 10$).
            \item $B_m$: The set of sample instances whose predicted confidence score falls into bin $m$ with cardinality $|B_m|$.
            \item $N$: Total number of evaluated test prediction instances across all $M$ bins.
            \item $\mathrm{acc}(B_m)$: Empirical accuracy observed for test samples assigned to bin $B_m$.
            \item $\mathrm{conf}(B_m)$: Average predicted confidence probability for test samples assigned to bin $B_m$.
            \item $|\mathrm{acc}(B_m) - \mathrm{conf}(B_m)|$: Absolute calibration error gap within bin $B_m$.
        \end{itemize}
        \item \textit{Regression Precision ($R^2$ \& MAE):} Quantify predictive fidelity of task latency ($\hat{\ell}$) and monetary token cost ($\hat{c}$):
        \begin{equation*}
        R^2 = 1 - \frac{\sum_{i=1}^N (y_i - \hat{y}_i)^2}{\sum_{i=1}^N (y_i - \bar{y})^2}, \qquad \mathrm{MAE} = \frac{1}{N} \sum_{i=1}^N |y_i - \hat{y}_i|
        \end{equation*}
        where $R^2$ denotes the coefficient of determination quantifying explained variance, $\mathrm{MAE}$ is the mean absolute error in latency (ms) or token cost (USD), $y_i$ is the empirical target value, $\hat{y}_i$ is the predicted metric, $\bar{y}$ is the empirical benchmark mean, and $N$ is the total count of evaluated traces.
    \end{itemize}
    \item Save optimized model checkpoints, export weight artifacts, and log diagnostic performance reports.
\end{enumerate}
